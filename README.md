# expense_tracker
This is a secure web-based Personal Expense Tracker built with PHP, MySQL, and HTML/CSS/JS. It allows users to register, log in, track multi-source income, record categorized expenses, and view real-time balances. Features include flexible reporting metrics (daily, weekly, monthly) and dynamic visual graphs to monitor spending habits.

 Personal Expense Tracker System

A lightweight, secure, web-based financial management application designed to help individuals record income, categorize expenses, track financial health, and monitor spending habits through interactive visual analytics.

🚀 Key Features
* User Authentication: Secure user registration and login system utilizing encrypted password hashing (`PASSWORD_BCRYPT`).
* Income Management: Add income sources (Salary, Business, Gifts, etc.) and keep a continuous running total.
* Expense Tracking: Log day-to-day spending under customizable categories (Food, Transport, Rent, Entertainment, Education, Other) with full delete management capabilities.
* Dynamic Financial Reports: Filter financial data instantly using Daily, Weekly, Monthly, or All-Time tracking views.
* Visual Analytics: Embedded interactive Pie Charts and Line Graphs powered by CanvasJS showing spending breakdowns and transactional trends.

🛠️ Tech Stack & Prerequisites
* Frontend: HTML5, CSS3, JavaScript (ES6)
* Backend: PHP (Native)
* Database: MySQL
* Local Server Environment: XAMPP (Apache & MySQL)
